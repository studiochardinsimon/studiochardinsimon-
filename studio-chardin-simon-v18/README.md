# Studio Chardin Simon — V11

Open `index.html` in a modern browser, or serve this folder with a static server. Upload the **entire folder** to your host to publish.

## Slides
The ten user-provided assets appear in the requested order, defined in `content.js`. Photos display for 3.5 seconds; videos play until finished. Three ProRes MOV uploads were converted to H.264 MP4 for web compatibility. All videos start muted. The bottom-right Sound on / Sound off toggle applies to all video slides, including future ones.

## Design
Desktop and mobile layouts retain the V10 styling (mobile 7:5 landscape crop, white background), About dropdown and black Contact page. Edit `styles.css` to customize.

## Notes
The sound setting is for the current page visit; browsers generally block unmuted autoplay until a user gesture. The button provides that gesture. The source MOV files are not included to keep the download manageable; converted MP4 files are included.
